# Mobile Previewer

A zero-dependency, vanilla JavaScript website for previewing any URL inside realistic, popular device frames — iPhone, Samsung, Pixel, iPad, and more. Paste a URL, pick a device, and see how the site looks and behaves on that screen.

No frameworks. No runtime dependencies. Just HTML, CSS, and JavaScript — built and bundled with Vite, styled with Tailwind CSS.

## Features

### Device Presets
- iPhone (e.g. iPhone 17 Pro Max), Samsung (e.g. Galaxy S26 Ultra with curved-edge display), Google Pixel, iPad, and other popular presets
- Multiple phone frame skins/themes to choose from
- Save custom device configurations for later use

### Preview
- URL input with live preview
- Zoom controls
- Reload button
- Fullscreen mode
- Demo browser chrome — preview the URL bar/toolbar styled like Chrome, Safari, Firefox, Brave, and Microsoft Edge

### Capture & Export
- Screenshot capture
- Export screenshots
- Record scrolling sessions as GIF/video
- Generate shareable preview links

### UI / UX
- Dark and light mode
- Keyboard shortcuts
- Drag-and-drop interface

## Tech Stack

- **Vanilla JavaScript** — no UI framework
- **Vite** — build tool and dev server
- **Tailwind CSS** — utility-first styling
- Zero runtime dependencies

## Getting Started

```bash
# Install dev dependencies (Vite + Tailwind only)
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

## Usage

1. Paste the URL you want to preview into the URL input field.
2. Choose a device preset (iPhone, Samsung, Pixel, iPad, etc.) and a frame skin.
3. Use zoom, reload, and fullscreen controls to inspect the page.
4. Switch the demo browser chrome to see how the page reads across different browsers.
5. Capture a screenshot, export it, or record a scrolling session as a GIF/video.
6. Share your preview via a generated link, or save the device configuration for reuse.
